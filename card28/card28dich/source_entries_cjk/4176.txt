区域类别:
- name: '大沙漠'
  description: 位于大陆东北角，是联合城的核心领土。这片广袤的沙漠向南与恒城和飞掠沙漠接壤，西临巴斯特，西北方则是辛昆半岛，东面则是无尽的海洋，但有一个叫做斯卡的小岛。

- name: '沼泽地'
  description: 位于大陆西南部，是一片被厚重雾气和植被覆盖的湿热区域。其西方斯坦沙漠，西南方蜘蛛平原，北面是边境之地，东北方连接闪域，东方是洼地泻湖，东南接壤骸骨荒原高地，南面则通往南方湿地。这里能见度极低，地形复杂。

- name: '闪域'
  description: 位于大陆中部，是一片点缀着无数风蚀湖的盆地。它夹在西边的沼泽地与东边的复仇之谷之间，北接边境之地。这里是游牧民的定居点。

- name: '复仇之谷'
  description: 位于大陆中部，闪域以东的山脉地带。其北面是灰色沙漠和目之地，东北方通往风暴口海岸，南面是洼地泻湖，东南是斯托伯的花园。这里有源自古代卫星的致命激光从天而降，对所有非骨人生物造成毁灭性打击。

- name: '灰色沙漠'
  description: 北达恒和灰色沙漠，东达伽特，南通复仇之谷，东南暴风口海岸，西方灰色沙漠，西北方黑色沙漠。

- name: '目之地'
  description: 北达恒城和飞掠沙漠，南通复仇之谷，也是大沙漠区域唯一通向大陆中央也就是沙漠西方的死亡之地。

- name: '恒'
  description: 位于大沙漠的东南方，是一片白色的石质荒漠。它东接风暴口海岸，西临飞掠沙漠，南面与目之地和灰色沙漠相连。这里坐落着联合城和商人行会的几座重要都市。

- name: '巴斯特'
  description: 位于大沙漠西北部，夹在大沙漠与圣国领土奥克兰之谷中间，北为辛昆半岛和黑暗之指，西为北部海岸和奥克兰之拳。作为双方势力的缓冲带和主战场，这里的城镇已化为废墟，土地荒废。

- name: '斯托伯的冒险'
  description: 位于大陆东南部，是一片巨大的洼地，北接斯托伯的花园，南临暗黑苍穹和灰烬之地，西面是骸骨荒原。这里有许多火山和酸性水域。

- name: '食人族平原'
  description: 位于大陆西北角，涵盖了洪泛地以北的高原及海岸。西面临海（利维坦海岸），东接隐匿森林和北部海岸。这里是野蛮食人族部落的主要活动区域。

- name: '皇家山谷'
  description: 位于大陆最东南端的山谷，西面为骸骨荒原，背面斯托伯的冒险，，东面紧邻暗黑苍穹。险峻的山脉将其环绕，这里是南部蜂巢女王的栖息地。

- name: '奥克兰之傲'
  description: 位于圣国领土的核心地带，是一片肥沃的绿色河谷。它北通重生镇，西邻奥克兰之湾，南接边境之地，东面被奥克兰之谷阻隔且通往飞掠沙漠是链接联合城腹地的唯一平原道路被奥克兰指盾拦截。这里是圣国农业的命脉。

- name: '奥克兰之臂'
  description: 位于大陆北部，指代夹住奥克兰之谷的两条平行山脉。它们将圣国的北方领土与大沙漠及洪泛地隔绝开来。

- name: '奥克兰之谷'
  description: 位于圣国最北方，是一片干燥的沙漠缓冲区。北临北部海岸，南通奥克兰之傲，东面则是联合城的领土飞掠沙漠。

- name: '奥克兰之湾'
  description: 位于圣国西部，是一片崎岖的荒地。西面与危险的雾岛接壤，东面连接奥克兰之傲。高级审判官塞塔镇守在南部的斯塔克镇，扼守着通往圣国内部的咽喉。

- name: '重生镇'
  description: 位于奥克兰之傲的正北方，坐落在群山之间。这里地形封闭，只有南部的奥克兰之傲和北部的隐匿森林两个出口，是圣国关押和劳役奴隶的巨型矿场。

- name: '边境之地'
  description: 位于大陆中央偏西，夹在北方的圣国（奥克兰之傲）与西方的沙克王国（斯坦沙漠）之间，南面是沼泽地。作为各大势力的缓冲无人区，这里盗匪横行。

- name: '斯坦沙漠'
  description: 位于大陆西部，是一片多山的岩石戈壁。西面和北面被虚荣谷环绕，南面为蜘蛛平原，西南方是阿拉克，东面是边境之地。这里是沙克王国的核心领土。

- name: '虚荣谷'
  description: 位于大陆西部，是一条红色的河谷，从西海岸一直延伸并包裹住斯坦沙漠的北部。北面与渣浑之地接壤。这里雨水充沛，但危险的野生动物（如喙嘴兽）成群结队。

- name: '雾岛'
  description: 位于大陆西北部，被服从之地、奥克兰之湾和虚荣谷包围。这是一片终年被浓雾笼罩的高原盆地，地形支离破碎，是被称作“雾人”的疯狂蜂巢族的巢穴。

- name: '阿拉克'
  description: 位于大陆西南腹地，被蜘蛛平原包围，是一个地形崎岖的中心区域。这里是虫之主的领地，四周不仅有群山，还有数不清的变异蜘蛛。

- name: '灰烬之地'
  description: 位于大陆极东南角，是一片被灰白毒气笼罩的废土。西北接斯托伯的冒险，西临皇家山谷。这里是第二帝国骨人军团最后的据点，环境恶劣。


- name: '钩子海滨'
  description: 位于大陆西南端的半岛，形状如钩。北面是南方湿地，漂流者的聚集地之一。

- name: '鱼形人之岛'
  description: 位于大陆正南方，与大陆主体（骸骨荒原南部）隔海相望。这座孤岛被鱼形人完全占据。

- name: '斯托伯的花园'
  description: 位于大陆东部，北接偏远之地，东临绿色海岸，西面是复仇之谷，西南则是斯托伯的冒险，南面是暗黑苍穹。这是一片干旱的高原山地，分布着巨大的古代机器人残骸。

- name: '黑色沙漠'
  description: 紧邻死亡之地（死地）的一片区域，通常指代死亡之地周边的黑色沙尘暴区域。位于大陆中部，连接着铁之谷和飞掠沙漠，环境有工业污染。

- name: '死亡之地'
  description: 位于大陆正中央，被铁之谷、复仇之谷和黑色沙漠包围。这里是旧帝国的工业中心，如今常年下着酸雨，地面皆是腐蚀性酸水。骨人的大本营黑沙城就位于此处。

- name: '飞掠沙漠'
  description: 位于大陆东北部，夹在西边的奥克兰之谷与东边的大沙漠之间双方互通的必经之路。这里是一片贫瘠的沙漠缓冲区，常常爆发小规模冲突，天狗地牢被安置于此。，

- name: '南方湿地'
  description: 位于大陆南部，北接沼泽地，南邻钩子海滨。这是一片比沼泽地更开阔但同样危险的湿地，拥有巨大的湖泊和成群的沼泽乌龟。

- name: '风暴口海岸'
  description: 位于大陆东海岸，北起恒城，南至绿色海岸。这是一片狂风肆虐的沿海地区，向内陆延伸至眼窝镇，是联合城与草寇帮争夺的区域。

- name: '辛昆半岛'
  description: 位于大陆最东北角的半岛，南面连接大沙漠。这里干旱且贫瘠，是联合城与北方蛮族、反叛农民交战的边疆地带。

- name: '隐匿森林'
  description: 位于大陆西北部，夹在重生镇、食人族平原和奥克兰之臂中间。这是一片植被茂密的丘陵地带，浪忍团隐居于此，以此对抗北方的食人族和东方的圣国。

- name: '偏远之地'
  description: 位于大陆东部，风暴口海岸以南，斯托伯的花园以北。这是一片沟壑纵横的荒芜山地，散落着旧帝国的废弃补给站。

- name: '禁岛'
  description: 位于风暴口海岸以东的海面上，是一座与世隔绝的岛屿。岛上遗迹众多，通常需要游泳或乘船才能抵达。

- name: '绿色海岸'
  description: 位于大陆东南部沿海，北接偏远之地，西临斯托伯的冒险，南接东极恶之地。这里虽然名为绿色海岸，却也是螃蟹掠夺者和各种土匪势力的活跃区域。

- name: '北部海岸'
  description: 位于圣国奥克兰之谷的正北方，是一片狭长的海岸线。西接食人族平原，东连黑暗之指。这里虽然有死猫村的残余势力，但深受食人族侵扰。

- name: '蜘蛛平原'
  description: 位于大陆西南部，斯坦沙漠以南，西面紧邻着险恶的阿拉克。这里土地贫瘠，植被枯黄，是沙克王国防御南方威胁的重要缓冲区。沙克战士在北部的“最终立足点”驻守，试图阻挡源源不断的蜘蛛大军北上。

- name: '利维坦海岸'
  description: 位于大陆西北角，东南方为食人族平原，西南方为铁之径。有着奇幻的紫色土地，利维坦在这里有位常见，许多废墟科技猎手在此地抢夺物资

- name: '铁之径'
  description: 位于大陆西北角，北面利维坦海岸，东面食人族平原，南面紫色沙漠，是陨落蜂巢族的家乡

- name: '紫色海岸'
  description: 位于大陆西北角，在铁之径的南方，狂战士之国的东北方，尖叫森林的北方。

- name: '狂战士之国'
  description: 位于尖叫森林的西边，顾名思义，沙克狂战士的家园

- name: '尖叫森林'
  description: 位于服从之地的西北方，是尖叫土匪帮的家园

- name: '服从之地'
  description: 位于雾岛北方的一片巨大采石场，向北摸索可以岛洪泛地，南则雾岛，东则隐匿森林，西则尖叫森林

- name: '渣浑之地'
  description: 位于大陆西侧，整体包裹住的雾岛的西方与南方外围，东则链接奥克兰之湾，南则为虚荣谷。此地极为贫瘠，不易生存，但些许难民仍在此地筑家

- name: '守望者之环'
  description: 位于蜘蛛平原的东南侧，许多赏金猎人在此地搭营，为了虫之主的赏金，以及科技猎人的一大研究城镇也在此地

- name: '舜'
  description: 大陆的西南部，这里是黑暗蜂巢族的家园，有着众多远古废墟，适合冒险家前来考古

- name: '方格山'
  description: 一片不自然的方格山脉，东北方通向沼泽地，西北方通向蜘蛛平原，南面只有方格山一个出入口

- name: '环形山'
  description: 位于舜的东方，钩子海滨的北方，一个巨大爆炸坑(不知道怎么形成的),出入口各有两个，一个是钩子海滨的链接处，一个是北方的方格山，据说有鬼怪出没

- name: '燃烧森林'
  description: 沼泽地的东方，闪域的南方，骸骨荒原高地的北方，一片酸雨不断的森林，的沼泽乌龟

- name: '剥皮人的漫游'
  description: 大陆中央区域，东面死亡之地，北面奥克兰之傲，南面闪域，西面边境之地，是圣国发展矿业的地方

- name: '黑暗之指'
  description: 大陆北方，辛坤半岛的西北侧，北部海岸的北边，是食人族部落的地盘

- name: '咆哮迷宫岛'
  description: 唯二道路为恒城的南面和伽特的东南方，只能从恒城过来，南面的暴风口海岸和禁岛只能渡海才能到达

- name: '伽特'
  description: 独特的景色，数量庞大的喙嘴兽群在此地，北面恒城，西面目之地，南面暴风口海岸

- name: '铁之谷'
  description: 大陆的中央，死亡之地的北方峡谷区域，北面需翻越高山才能到奥克兰之傲，东面最近的黑色沙漠

- name: '极恶之地'
  description: 位于大陆东南部沿海，就在绿色海岸的下方，往西走到达极恶之地，往南面渡海可以到达灰烬之地

- name: '极恶之地'
  description: 东为东极恶之地，南面渡海到达灰烬之地，西方通向暗黑苍穹，北面通过峭壁山才可到达斯托伯花园

- name: '峭壁山'
  description: 这是大陆东南一片高原地区，四通八达，中间大裂谷穿过南面极恶之地和暗黑苍穹，北面斯托伯的花园，西面斯托伯的冒险

- name: '温德河'
  description: 奥克兰之傲的母亲河

- name: '暗黑苍穹'
  description: 这里是灰烬之地的门口，西边是大山环绕的皇家山谷，南面为骗子捷径，北面是斯托伯的冒险和极恶之地

- name: '骗子捷径'
  description: 大陆的南边沿海地区，北面的大山脉是皇家山谷，东面链接暗黑苍穹，西面链接骸骨荒原南部，一个香蕉形状，冒险家戏称香蕉道,是相对安全从骸骨荒原南部前往暗黑苍穹的地方
