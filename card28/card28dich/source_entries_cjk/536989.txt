武器类型有钝器-砍刀-大型武器-武士刀-军刀-长柄刀-弩-弓-武术(空手):
    - name: 重型十手,铁棒,铁棍,十手,棍棒,钉头棒
      Type:'钝器'
      Disadvantage:攻击距离短，缺乏切割流血能力，依赖贴身肉搏，这使得使用者在面对长兵器时风险极大。且挥舞沉重的钝器极耗体力
      Advantage:室内战很适合,高重量意味着不主动切割对手的肢体，而是以击碎为目标，对重甲敌人能造成护甲凹陷，内骨碎裂的威胁

    - name: 战斗砍刀,血肉砍刀,长砍刀,月刃刀,圣骑士十字剑,环首直刃刀
      Type:'砍刀'
      Disadvantage:重心靠前导致回防速度慢，依赖势大力沉的劈砍，一旦挥空，巨大的硬直时间容易被反击
      Advantage:以破甲与大出血为首的武器，对于损坏骨人的肢体也有很好的协助，击中一下如果不立刻包扎会有失血过多的风险。

    - name: 落日,平板剑,分段斧,牛角斧,放逐平板剑
      Type:'大型武器'
      Disadvantage:极高的力量门槛与缓慢的攻速，室内狭窄环境极易施展不开，一旦被贴身或第一击未中，便是破绽大开。
      Advantage:绝对的力量压制与群体杀伤。挥舞起来移动的铁墙，任何格挡在绝对的质量面前都是徒劳。一击可以同时扫倒多名敌人

    - name: 忍者之刃,武士刀,无锷武士刀,野太刀,长卷刀,胁差,铁扇
      Type:'武士刀'
      Advantage:极致的速度与轻盈。出刀收刀极快，能够利用对手攻击后的瞬间空隙进行肢体切割。造成出血是重点，通过切断肢体快速削弱对手战斗力。
      Disadvantage:若非特殊制作，此武器对重甲乏力，不适合硬碰硬的格挡。

    - name: 重型长柄刀,长刀,长柄武士刀,长柄刀,杖
      Type:'长柄刀'
      Advantage:攻击距离的绝对优势一寸长一寸强，能够在敌人武器触及自己之前先造成伤害，且对多名敌人有很好的限制打击效果
      Disadvantage:一旦被突破近身，长杆将成为累赘，且在狭窄空间难以挥舞。

    - name: 沙漠军刀,异域军刀,开孔军刀,斩马军刀,长剑,九环刀
      Type:'军刀'
      Advantage:攻守平衡。护手设计提供了额外的防御加成，适合防御反击战术。其重量适中，既有一定的破甲能力，又能维持不错的挥舞频率，是战场上容错率最高的武器
      Disadvantage:缺乏爆发力，速度不及武士刀，威力不及重武，面对极端特化敌人时容易陷入平庸的被动。

    - name: 废品弩,牙签弩,射弩,弹簧弩,旧世界弩Mk1,旧世界弩Mk2,鹰之十字弩,鱼叉
      Type:'弩'
      Advantage:惊人的穿透力与停止作用，能够击穿厚重的板甲，大威力弩箭的动能甚至能将敌人带得倒退或跌倒，直接造成器官破裂的致命伤造成出血。
      Disadvantage:装填期间是绝对的防御真空期，且极易误伤友军。

    - name:长弓,短弓,巨弓,猎人弓
      Type: '弓'
      Disadvantage:极耗耐力，无法长期保持瞄准，单发破甲能力通常弱于弩。
      Advantage:持续压制能力与抛射战术。射速远高于弩，可以保证灵活的情况下，火力不停。箭矢造成的持续出血和插在身上的箭杆会严重阻碍敌人的动作。
- name: 空手
      Type: '武术'
      Disadvantage: 攻击距离是所有流派中最近的，必须“贴脸”肉搏。最大的致命伤在于“无法格挡”，防御完全依赖身法闪避，一旦体力耗尽或空间狭窄无法躲闪，便是以肉身抗刀，容错率极低。。
      Advantage: 极致的爆发力与单点破坏力。不再受制于武器的重量与拔刀速度，全身皆为利器。高深的武术家一记飞踢能产生比重武更可怕的动能，直接将敌人的肢体踢飞或造成瞬间昏厥。且因为不携带武器，负重极轻，移动与攻速如鬼魅般难以捕捉。

城镇防御性武器：通常在一些富饶的城市围墙上所有的炮塔。
- 双筒鱼叉炮塔：最为爆炸性的武器，拥有了双发功能。
- 鱼叉炮塔：和高级十字弩一样强力，但是更容易使用、填充子弹更快。缺点在于它需要通电操作
- 装载式十字弩：安装在转轴上的重型十字弩。它有180度的射击弧度，最好安装在墙上。对付重甲就没那么厉害了。
