  世界:
    天数:
      type: number
      check:
        - 在角色进行长时间休息（如深夜转到第二天上午）或长途旅行后增加。
    时间:
      type: "'上午' | '中午' | '下午' | '傍晚' | '深夜' | '上午 HH:MM' | '中午 HH:MM' | '下午 HH:MM' | '傍晚 HH:MM' | '深夜 HH:MM'"
      check:
        - 根据事件的推进和时间的消耗进行更新，保持逻辑连贯。
    当前事件:
      check:
        - 简要描述当前正在发生的最核心的事件或主控正在执行的主要行动。

  我方派系名称:
    check:
      - 仅当角色创建了自己的派系或通过剧情改变了派系名称时更新。

  小队成员.${小队名}:
    金钱:
      type: number
      check:
        - 通过交易、完成任务奖励、搜刮战利品等行为发生变化。
    所处位置:
      区域:
        check:
          - 当该小队移动到新的区域地图（如从“大沙漠”移动到“边境之地”）时更新。
      城镇:
        check:
          - 当该小队进入或离开一个具体的聚落（如城市、村庄、哨站、废墟）时实时更新。
          - 示例: '野外', '枢纽城外', '枢纽城'。
          - 如果没有靠近城镇必须写 '野外'
  # 以下为适用于所有角色（小队成员/视野/异地）的通用规则
  '${小队成员.${小队名}.成员|小队成员.${小队名}.视野|异地}.${角色名}':
    名字:
      check:
        - 必须完全等于角色在正文中的纯中文称呼，存在改名时根据剧情更新。
    年龄:
      type: 'number | string'
      check:
        - 满365天（即世界.天数增加365）增加1岁。
    身份:
      check:
        - 根据角色当前的社会地位更新，如“自由人”、“奴隶”、“百姓”、“贵族”等。
    等级:
      type: number
    种族:
      check:角色种族
    外貌:
      check:
        - 根据角色背景生成10-20字描述(包含瞳孔颜色，发型，体态，身形等)。
        - 当遭遇导致外形变化的事件（如留疤、毁容、易容、衰老）时更新。
    体型:
      format: "数字+m，例如'1.75m'"
      check:
        - 格式必须为数字+m，不使用‘矮小’、‘高大’等模糊描述。
    状态:
      check:
        - 根据健康状况（如血量归零变'昏迷'/'死亡'）或特定剧情效果（'中毒'、'被囚禁'）更新。
    立场:
      type: "'友方' | '中立' | '敌方'"
      check:
        - 小队成员固定为'友方'。
        - 角色的立场是相对于“我方派系”而言的。
        - "友方 -> 敌方/中立: 当角色被我方攻击、背叛，或我方行为严重触犯其所属派系利益或个人底线时更新。"
        - "中立 -> 敌方: 当角色被我方主动攻击、偷窃被发现，或我方在其面前进行犯罪行为时更新。"
        - "中立 -> 友方: 当角色接受我方帮助、完成其委托、或其所属派系与我方结盟时更新。"
        - "敌方 -> 中立/友方: 当角色在战斗中被放过、被从困境中解救，或通过外交手段改善其所属派系关系时更新。"
    派系:
      check:
        - 角色所属派系，无派系填'漂流者'。
    经验值:
      当前:
        type: number
        check:
          - 初始默认为0，通过战斗、探索、完成任务获取。
          - 视野和异地不会获取经验，因此视野的npc经验默认0
    创伤:
      type: |-
        {
          [部位名 in '左臂' | '右臂' | '左腿' | '右腿' | '头部' | '胸腹']?: {
            等级: number; # 范围0-4
            描述: string;
          }
        }
      check:
        - "当角色的四肢或躯干在战斗或事件中受伤时，添加或更新对应部位。"
        - "等级: 0:无伤, 1:擦伤, 2:负伤, 3:重创, 4:断肢。根据伤害严重程度设定。"
        - "描述: 简要描述伤情，如'一道深深的刀伤'或'肢体被完全切断'。"
        - "治愈时应降低'等级'或移除该条目。"
        - "更换义肢后，移除对应创伤条目，并在'临时特质'中新增义肢描述。"
    主武器: &WeaponRule
      type: |-
        {
          名字: string; 种类: string; 品质: string; 介绍: string;
          伤害骰: string; 伤害类型: string; 价值: number; 重量: number;
        }
      check:
        - "种类格式须为: '武士刀类'|'砍刀类'|'军刀类'|'钝器类'|'长柄类'|'大型类'|'武术'|'弓'|'弩'|'特殊远程'|盾牌|。"
        - "当角色空手时，种类为'武术'，伤害默认1d8，重量0。"
        - "介绍文本建议20字以内。"
        - "伤害类型格式为 '类型:比例' (仅限钝伤和切割), 多种类型用'/'分隔 (例: '钝伤:1.0' 或 '切割:0.2/钝伤:0.8')。"
        - "重量: number; 必须为数字。"
    副武器:
      <<: *WeaponRule
      check:
        - 无装备时设为名字'无'，种类'无'。
    护甲:
      type: |-
        { 种类: '重甲'|'中甲'|'轻甲'|'无甲'; '防护能力(DR)': number; 介绍: string; 重量: number; }
      check:
        - 介绍建议30字以内，描述全身穿着。
        - "重量: number; 必须为数字。"
    护甲:
      type: |-
        { 种类: '重甲'|'中甲'|'轻甲'|'无甲'; '防护能力(DR)': number; 介绍: string; }
      check:
        - 介绍建议30字以内，描述全身穿着。
    属性.${STR|DEX|PER|TGH|WIL|INT|CHA}:
      type: |-
        { 基础: number; }
      check:
        - "仅在升级加点或剧情永久改变时更新'基础'值。"
    特质:
      type: 'Record<string, string>'
      check:
        - "键为特质名，值为描述文本 (例: '坚韧': '皮肤粗糙，体质+5')。"
        - "描述文本需包含可供脚本解析的具体数值效果。描述文字建议5-15字以内。"
        - "根据角色背景和重要经历生成。"
    临时特质:
      type: |-
        {
          [临时特质名: string]: { 描述: string; 消除: string; }
        }
      check:
        - "当角色因环境、事件或物品获得临时状态时添加。"
        - "描述: 需包含具体数值效果，如'全属性-15', '力量-5'。"
        - "消除: 必须明确定义消除条件，如 '吃饭', '休息一晚', '14h后', '使用解毒剂'。"
        - "【核心规则】当剧情中满足'消除'条件时，必须将对应的临时特质从此对象中移除。"
    血量:
      最大:
        type: number
        check:
          -   300+【体质*3】+等级。
          -  (注‘体质’是根据其"基础"+"加成"后的值)
      当前:
        type: number
        check:c
          - 角色在受到伤害时减少，接受治疗时增加。最低为0。
          - "当血量降至0或以下时，角色的'状态'应更新为'休克'或'死亡'。"
    背包.物品:
      type: |-
        {
          [物品名: string]: {
            分类: '食物'|'农作物'|'饮品'|'武器'|'装备'|'医疗用品'|'科研道具'|'任务道具'|'矿石'|'布料'|'金属材料'|'其他';
            介绍: string; 数量: number; 重量: number; 价值: number;
            # 对于武器/装备，还需要包含它们本身的结构属性
          }
        }
      check:
        - "当角色拾取、购买、制造、消耗或丢弃物品时，更新'数量'。"
        - "分类必须从指定选项中选择，不明确则选'其他'。"
        - "介绍应简要描述外观或用途，5-15字即可。"
        - "数量为0的物品会被脚本自动移除，无需手动删除。"
          - 开币默认0kg
    人际关系:
      type: |-
        {
          [角色名: string]: { 好感度: number; 关系: string; 看法: string; }
        }
      check:
        - "【核心规则】此字段记录的是【当前角色】对【其他角色】的看法和情感，是完全主观的。例如，'主角'条目下的'人际关系'记录了主角对别人的看法，而'雷诺'条目下的'人际关系'则记录了雷诺对别人的看法。"
        - "【好感度】:"
        - "  - 数值范围为 -500 至 500，反映当前角色对目标角色的个人情感倾向。"
        - "  - 根据角色间的直接互动（如帮助、攻击、赠礼、侮辱、共同经历等）实时增减。"
        - "【关系】:"
        - "  - 描述角色间客观的、相对稳固的社会身份或事实联系，例如：'队友'、'兄妹'、'师徒'、'仇人'、'雇佣关系'。"
        - "  - 此字段由好感度间接决定。当好感度为负，血缘关系如'兄妹'关系依然是'兄妹'。"非血缘关系如'好友'关系会变成是'敌人'。"
        - "  - 因此根据关系要看此关系的重要程度
        - "  - 在发生能够定义或改变角色社会关系的重大剧情事件时（如结拜、收徒、确立恋情、表示厌恶、解除雇佣等）才应更新。"
        - "  - 好感度可以作为改变'关系'的【前置条件】或【催化剂】。例如，长期的高好感度可能触发从'队友'转变为'恋人'的剧情。"
        - "【看法】:"
        - "  - 记录当前角色在心里对目标角色的具体评价或想法，是一句心理独白。"
        - "  - 应随着近期的互动或对目标的新发现而更新，反映角色心理的动态变化。"
        - "  - 示例10-15字左右：'虽然年轻，但脑子很清醒。' 或 '太沉默了，不好判断。'"


  # 专属位置操作规则
  小队成员.${小队名}.成员:
    check:
      - "【移动】当一个角色明确同意加入小队时，必须使用'move'操作，将其条目从`/视野`或`/异地`完整移动到此。"
      - "【保留数据】移动操作必须保留角色所有现有数据（血量、创伤、装备等），不得重新初始化。"
      - "【来源】新成员必须是已存在于`视野`或`异地`中的角色。"
      - "【互斥】小队成员、视野、异地三个集合完全互斥，同一角色只能存在于其一。"
  小队成员.${小队名}.视野:
    check:
      - "【创建规则】当一个拥有明确'名字'的新角色【首次】与当前角色发生直接互动（如对话、战斗、交易等内容）时，必须为其创建完整的变量结构并添加到'视野'中。"
      - "【创建细则】创建时，应优先查找其世界书背景，若无，则根据其剧情表现和身份合理生成属性、特质、等级和种族。"
      - "视野中已有角色的状态（如血量、立场）应根据战斗和互动实时变化。"
      - "【移除规则：离开】当剧情明确描述视野中的某个角色'离开场景'、'消失'、'走远'，且不需要再追踪其动向时，应将其从此变量中 remove 移除。"
      - "【移除规则：换场】当主角明确'进入'或'离开'一个区域导致场景内角色完全刷新时，应 remove 移除所有不跟随主角的旧场景角色。"
      - 注意：心理想法、人际关系不要一起更新出现，根据后续了解加以变化
      - "注意：角色即使死亡或血量为零，只要其躯体仍在主角身边，就不应从视野中移除。"
  异地:
    check:
      - "【转移】当某个遇到的已知名字的角色且存活时要与主角分别，需追踪其状态和动向，必须使用 'move' 操作将其从`/小队成员`或`/视野`完整移动到`/异地`中。"
      - ”如果其已经死亡，或者没有专属的名字时候(专属名字指的是：世界书角色或者有名有姓的（龚宇圣骑士，常悦等），非专属名字：高个子圣骑士，生气的武士，科技猎手A等），不要移入`/异地`“
      - "【位置更新】移入或在该地发生位移时，必须更新其特定的 `所处地址` 字段，简要标明其当前位置（如'大沙漠'，'斯昆城'，'前往枢纽的路上'）。"
      - "【回归】当异地中的角色重新回到主角身边并发生互动时，使用 'move' 操作将其从`/异地`移回`/视野`或`/小队成员`中。"
      - 注：小队成员、视野、异地三个集合完全互斥，同一角色只能存在于其中一个。

  局势:
    已知派系:
      type: |-
        { [派系名称: string]: { 好感度: number; } }
      check:
        - "与某派系发生接触时记录其好感度。"
        - "若好感度降至 -30 及以下，需将其移至【敌对派系】。"
        - "若好感度升至 50 及以上，需将其移至【友方派系】。"
        - 只要遇到新派系(如'圣国''联合城''沙克王国')，就必须记入至已知派系(注：土匪,强盗,漂流者等没有具体派系的不用写)
        - 根据<派系好感度变化>来更新好感度
    敌对派系:
      type: |-
        {
          [派系名称: string]: {
            好感度: number;
            敌对原因: string;
          }
        }
      check:
        - "当某派系好感度 <= -30 时，记录于此，并简要写明敌对原因（如被宣战、攻击领袖等）。"
    友方派系:
      type: |-
        {
          [派系名称: string]: {
            好感度: number;
            结盟原因: string;
          }
        }
      check:
        - "当某派系好感度 >= 50 时，记录于此，并简要写明结盟原因（如完成重大任务等）。"

  任务系统:
    type: |-
      {
        [任务名: string]: {
          描述: string;
          奖励: string;
          主任务状态: '进行中' | '已完成';
          子任务: {
            [子任务名: string]: {
              进度: { 当前: number; 目标: number; };
              状态: '进行中' | '已完成';
            }
          }
        }
      }
    check:
      - 接受新任务时添加新条目。
      - 满足子任务条件时，更新'进度.当前'值。
      - '进度.当前'达到'目标'时，将子任务'状态'更新为'已完成'。
      - 复杂的任务应拆分为多个子任务。


  闲言.当前内容:
    check:

      type: |-
        [{
          日期: number;
          描述: string;
        }]
      check:

        - "此列表为永久性历史记录，只能添加，不能删除或修改。"
